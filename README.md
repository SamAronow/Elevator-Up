This is a project to play the online card game elevator up: https://elevator-up.vercel.app/

To play use the website, from the code point of view it is organized through a index page that acts as the home page then a room page which is like a lobby
and finally the game itself. Each page is divided into the HTML and css front end files and then a file for the back end. It uses google firebase
as the database to hold game information and relay information between players and is hostted on vercel
